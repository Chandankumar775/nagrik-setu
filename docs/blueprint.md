# **App Name**: Citizen Connect

## Core Features:

- Issue Reporting: Allow citizens to report civic issues with photos, voice descriptions, and location data. Submissions do not require an account.
- Geolocation: Automatically capture the user's current location upon report submission using the device's GPS.
- Report Status: Enable citizens to view the status of their submitted reports using a unique tracking ID generated upon submission.
- Admin Interface: Provide a secure admin interface (authentication not part of MVP) to view, filter, and manage reported issues.
- Intelligent Categorization Tool: Use AI to categorize the reports automatically and tag the category to the report.
- Interactive Map: Display reported issues on an interactive map, enabling admins to quickly visualize problem areas.

## Style Guidelines:

- Primary color: Blue (#2E9AFE), reflecting trust and civic responsibility.
- Background color: Light gray (#F5F5F5), for a clean and neutral backdrop.
- Accent color: Orange (#FF8A65), used for highlighting interactive elements and calls to action.
- Font pairing: 'Poppins' (sans-serif) for headings and short descriptions, 'PT Sans' (sans-serif) for body text to improve readability.
- Use clear and simple icons from a library like Font Awesome for issue categories and status indicators.
- Employ a card-based layout for reports and a sidebar navigation in the admin dashboard for easy access to different sections.
- Implement subtle animations like fade-ins for loading content and hover effects on interactive elements to enhance user experience.
